# Gigma

Локальный векторный редактор для Windows с русским интерфейсом. Холст, слои, инспектор свойств и прототипы работают с документами на вашем компьютере. У приложения есть собственный формат `.gigma`.

## Открыть редактор

Запустите переносимый **Gigma-0.2.5-Windows-x64.exe**. Выберите **Новый дизайн**, **Новая доска** или **Открыть пример**. Образец Forma создаёт отдельный редактируемый документ.

Клавиша **F** создаёт кадр, **R** рисует прямоугольник, **P** включает карандаш, **T** добавляет текст. Выберите инструмент, затем нажмите или потяните на холсте. Дважды щёлкните текст, чтобы продолжить ввод. Для сохранения достаточно завершить действие. После надписи **Все изменения сохранены** файл уже записан на диск.

Кнопка **Документы** внизу возвращает в библиотеку. **Папка на ПК** открывает системную папку **Документы/Gigma**. Там лежат файлы с постоянными идентификаторами в именах. Названия для списка документов хранятся внутри файлов.

## Возможности версии 0.2

- Документы и страницы, переименование, поиск, обложки и импорт редактируемой копии.
- PNG, включая изображения из старых документов Illustrator, по умолчанию показываются в режиме «Чёткие пиксели». Для фотографии выберите слой изображения и включите «Сглаживание» в инспекторе. Выбор сохраняется в документе и используется при экспорте SVG и PNG.
- Холст с перемещением, масштабом от 2 до 3200 процентов, точечной сеткой и командой «Вписать страницу».
- Кадры, прямоугольники, эллипсы, линии, стрелки, свободное рисование, многострочный текст и вставка PNG, JPEG, WebP.
- Выделение рамкой и через Shift, перемещение, изменение размеров, порядок слоёв, группы, блокировка, скрытие, выравнивание и дублирование.
- Заливка и обводка, толщина, непрозрачность, скругление, поворот отдельных фигур, гарнитура, кегль и начертание.
- Горизонтальная и вертикальная раскладка содержимого контейнера. Изменения интервалов применяют раскладку, кнопка «Разложить объекты» пересчитывает её вручную.
- Вкладка «Прототип» связывает выбранный объект с кадром. Кнопка ▶ открывает просмотр, переход выполняется по щелчку.
- Экспорт страницы или выделения в SVG и PNG. Экспорт Gigma включает все страницы и встроенные изображения. Импорт создаёт отдельный документ.
- История текущего сеанса до 128 действий с ограничением размера в 64 МиБ. Сохранённый документ включает результат редактирования.

## Рабочая среда 0.2

Редактор открывается в тёмной теме. Кнопка с шестерёнкой доступна над холстом, а «Настройки» — также в библиотеке. Здесь меняются тема, обои, их видимость, шаг сетки, привязка, сдвиг стрелками и число сторон многоугольника. Обои — часть рабочего пространства этого профиля. Экспорт рисунка и файл документа включают только содержимое страниц.

Двойной щелчок по тексту или щелчок инструментом **T** по существующей надписи включает ввод. Enter добавляет строку, Ctrl+Enter завершает ввод. Угловая ручка масштабирует текст, боковая меняет ширину строки и включает перенос. Поле «Размер» задаёт кегль числом.

Чтобы выделить один рисунок из нескольких деталей, обведите его рамкой на холсте. Рамка учитывает видимые контуры и пиксели PNG. Shift + щелчок добавляет или убирает отдельную деталь. Слой Illustrator целиком можно выбрать по имени в панели слоёв.

Инструменты расположены в вертикальной панели слева. **D** выбирает объект внутри группы, **Y** рисует многоугольник, **I** берёт цвет объекта, **E** стирает объекты. Новые фигуры и кадры используют цвет, показанный в палитре. Два образца позволяют переключать рабочий цвет. При перетаскивании в спектре или на полосе тона выделение окрашивается сразу, а один Ctrl+Z отменяет весь жест. Палитра содержит поле насыщенности и яркости, полосу тона и переключатель цветов. Коррекции применяются к выделенному слою и сохраняются в документе. Панель слоёв позволяет искать по типу, менять наложение, непрозрачность и заполнение.

Для рисования нажмите **P**. Справа появятся пресеты, диаметр, непрозрачность, сглаживание, минимальная толщина и кривая нажима. Меньшее значение кривой даёт более толстую линию при лёгком касании. Метка в тестовой области показывает тип указателя и нажим, который сообщает драйвер. Для работы с XP-Pen Artist 15.6 Pro в Windows включите Windows Ink в драйвере планшета, если перо определяется как мышь. Профиль толщины записывается в точки штриха и сохраняется в SVG и PNG.

Окно «Расширения» включает лесную палитру и устанавливает локальные JSON-палитры. Образец файла приведён в самом окне. Установленные наборы появляются под выбором цвета.

**Открытие Illustrator для Windows.** В библиотеке нажмите **Открыть AI со слоями**. Gigma создаст локальный документ. На общем холсте сохраняются взаимное положение монтажных областей, порядок объектов, названия слоёв и подслоёв, видимость и блокировки. Слева можно выбрать отдельный объект, скрыть его, переместить или изменить размер. Кнопка **Поместить AI** в редакторе добавляет содержимое в текущую страницу одной отменяемой операцией.

У простых контуров можно менять заливку и обводку. Контуры и градиенты импортируются в векторном виде, а вложенные растровые изображения сохраняют разрешение, которое передал Illustrator. Если внешний файл потерян, Gigma ищет встроенное изображение в PDF-совместимой части AI и возвращает его на исходный слой. При отсутствии однозначного совпадения на месте изображения появится подписанная рамка. Остальные объекты откроются для редактирования. При восстановлении цвета изображений без встроенного профиля зависят от рабочего профиля Illustrator. Текст Illustrator передаёт в кривых. Исходный AI может занимать до 128 МиБ, а разобранный документ должен поместиться в лимит сохранения Gigma (32 МиБ). Сложная группа с маской или эффектом может стать одним объектом, а вид эффектов зависит от того, как Illustrator экспортирует их в SVG. Изменения сохраняются в формате Gigma. Для чтения исходного AI нужен установленный Illustrator с доступной автоматизацией Windows. Экспорт **AI · через Illustrator для Windows** записывает выделение или текущую страницу в новый PDF-совместимый AI.

## Хранение и обмен с браузером

Windows-программа и локальный сервер используют одну папку **Документы/Gigma**. После изменения в одном окне вернитесь в библиотеку другого и заново откройте документ. При одновременной записи одной версии программа сообщает о конфликте и позволяет сохранить свои изменения отдельным документом.

Автосохранение начинается через полсекунды после последнего завершённого действия. Программа записывает временный файл, синхронизирует его и заменяет основной. Суффикс `.gigma.bak` обозначает предыдущую версию. Если основной файл повреждён, открывается доступная резервная копия. При обычном закрытии Windows-программа завершает ввод и ждёт записи. Кнопка «Скачать копию» позволяет забрать документ при ошибке записи.

В Chrome на локальном адресе незаписанные изменения дополнительно сохраняются в черновике браузера, пока хватает места в его хранилище. При следующем запуске с того же адреса и профиля черновик восстанавливается. Для больших документов дождитесь статуса сохранения перед закрытием вкладки. Для переноса на другой компьютер используйте **Экспорт → Gigma**, затем **Импорт .gigma**.

## Запуск из исходников

Проверенное окружение включает Windows x64 и Node.js 26. В каталоге репозитория выполните:

```powershell
npm ci
npx --no-install install-electron
npm run build
npm start
```

Для браузерного режима запустите **Gigma-Web.cmd** или выполните `npm run web` после сборки. Редактор откроется по адресу [127.0.0.1:5180](http://127.0.0.1:5180). Оставьте окно локального сервера открытым на время работы. Если порт занят, сервер сообщает об ошибке.

```powershell
npm test
npm run test:e2e
npm run package
```

Браузерной проверке нужен установленный Chrome. Сквозной тест запускает Windows-программу и Chrome с изолированными документами, закрывает и повторно открывает программу, сверяет данные на диске, проверяет восстановление вкладки и размеры экспортированного PNG. Сборка создаёт переносимый файл в `release/`. Первичная установка зависимостей, движка Electron и упаковщика требует подключения к интернету.

## Управление

| Действие | Клавиши |
| --- | --- |
| Выделение, кадр, прямоугольник, эллипс | V, F, R, O |
| Линия, стрелка, карандаш, текст | L, A, P, T |
| Панорамирование | Пробел + перетаскивание, средняя кнопка или H |
| Масштаб, вписать, 100% | Ctrl + колесо, 1, 0 |
| Отменить, повторить | Ctrl+Z, Ctrl+Shift+Z или Ctrl+Y |
| Копировать, вырезать, вставить, дублировать | Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+D |
| Группа, разгруппировать | Ctrl+G, Ctrl+Shift+G |
| Сдвиг на 1 или 10 | Стрелки, Shift + стрелки |
| Сохранить | Ctrl+S |

## Границы версии

Gigma реализует основной процесс векторного редактирования. Возможности совместной онлайн-работы, компоненты с вариантами, сторонние исполняемые плагины, импорт файлов Figma `.fig` и облачная синхронизация между компьютерами остаются за пределами версии 0.2. Буфер объектов действует внутри приложения. Дизайн и доска используют общий набор инструментов. Размер документа ограничен 32 МиБ, количество объектов — 20 000, количество страниц — 32.

Исходный код программы хранится в GitHub. Пользовательские документы, резервные копии, файлы тестов и сборки исключены из Git. Для тестирования переменная `GIGMA_DATA_DIR` задаёт отдельный каталог для документов и профиля. `GIGMA_PORT` задаёт порт локального сервера.
